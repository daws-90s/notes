EFS Static
==========
1. install EFS drivers
kubectl apply -k \
    "github.com/kubernetes-sigs/aws-efs-csi-driver/deploy/kubernetes/overlays/stable/?ref=release-3.4"
2. add EFSCSIDriverPolicy to IAM role
3. create EFS, allow SG port 2049
4. create PV
5. create PVC
6. claim through pod volume

3. if a pod is delete and recreated, it should go and attach to the same volume it was using earlier

deployment is for stateless applications, there all the replicas can use same volume..
k8s created another resource called for statefulset for stateful applications

deployment vs statefulset
==========================
1. deployment is stateless applications, statefulset is for stateful applications
2. all pod replicas in deployment use same storage, pods in statefulset use differnt storage for every  pod.
