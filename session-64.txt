TopologySpreadConstraint
========================
if we want EKS HA. generally 2 zones for HA, 2 nodes. 1 node for 1 zone

AWS always recommends 3 zones for zone level HA and. every zone must contain 2 nodes for node level HA

so every zone should contain min 2 nodes. total 6 nodes and every node should have 1 pod replica...6 pods

3 nodes 1-1-1
========
1 pod -> 1-0-0 -> unsafe
2 pods -> 1-1-0 -> partly safe
3 pods -> 1-1-1 -> safe
4 pods -> 2-1-1
5 pods -> 2-2-1
6 pods -> 2-2-2

if we choose odd number of replicas, there is always 1 pod difference

we use TopologySpreadConstraint to spread the pods across nodes and zones for HA.

2 nodes 1-1
===========

replica count = node count * multiplies of 2

2 nodes in 1a 1 node in 1b -> 1a-1 - 1a-2 - 1b

2 pods -> 1-0-1
3 pods -> 1-1-1
4 pods -> 1-1-2
5 pods -> 2-1-2

min 2 zones give us zone level HA, each zone should have atlest 2 nodes for nodelevel HA
