What is model?

A model is a program learned from billions of examples, it is trained on huge amount of data to generate patterns. it is completely from traditional program. normal programs works on rules. for example send an alert if there is cpu usage of 90%. But models can understand different situations through the training, so they can predict the response to the different situation it never faced...

these patterns are called as parameters. 70B it is trained 70 billion parameters.

MCP
===
Model context protocol. API is a strict contract document to share the information between multiple systems

URL, method, Request, content-type, etc..

suppose if you want to work 50 systems, we need 50 integrations minimum...

MCP servers are developed for agents to get the information without writing the integration code. for example if agent wants to send an email, it will first contact the gmail MCP server and ask for its capabilities/tools...

Gmail -> system
tools/capabilities -> send email, read email, delete spam, summerise all the email from particular person,
Parameters -> sender, subject, body, to, etc...

===========
