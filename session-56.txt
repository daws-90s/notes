nodeAffinity
============
requiredDuringSchedulingIgnoredDuringExecution -> k8 will not schedule, if the criteria does not matched
preferredDuringSchedulingIgnoredDuringExecution -> K8 will try to match, if not matches it will schedule the pod in any other node

IgnoredDuringExecution -> if the node labels are changed when the pod is scheduled and running, no effect. pod will continue to run

1. Schedule -> while scheduling we have options required and preferred
2. Execute -> while executing k8 tried to put 2 options again required and preferred, but they withdrawn required options
