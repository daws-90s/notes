freestyle job
=============
everything is in jenkins UI, no version control, cant restore, cant track easily who did the change, complex logic, no visualisation, cant reuse, etc...

pipeline job
============
version control, review the changes through PR, restore, reuse, etc

declarative vs scripted
========================
scripted -> old way of jenkins pipelines, groovy based(like java). pipeline code compiles at run time. pipeline code cant check for errors before execute. you can have more control

declarative -> new way of jenkins pipeline, easy syntax, it checks for errors before started execution.

Master Node architecture
========================
master node cant take the builds, it can just get the trigger and assign node to run the build. we can have multiple nodes based on diff configurations, seperate node for java projects, nodejs projects, ios projects, android env, etc...
