USER
====
docker containers should not run with root access, we have to run USER instruction atleast one step before CMD

WORKDIR
======
used to move to another directory inside docker image

ARG
===
ARG instruction is used to set the build variables inside dockerfile. we can have default values and we can override them from cmd line using --build-arg var_name=value
ARG can be the first instruction before FROM to supply the version to base OS. It cant be accessed again after FROM instruction

ARG vs ENV
==========
1. ARG is used to set the build time variables, It can't be accessed inside containers
2. ENV is used to access key value pairs inside container.

ONBUILD
=======
this instruction is used to set the conditions if someone is using our image as their Base image. ONBUILD instruction runs when someone is using our image as their base image.
